# VendingMachineWithGUI

This project is a graphical vending machine simulation built using Python and Tkinter. It allows users to buy items, restock inventory, and view live updates through a user-friendly interface. The application integrates core programming concepts such as object-oriented design, GUI development, and user interaction.

---

## Features

- Purchase items such as Soda, Water, Coffee, Chips, and Candy
- Restock any item via dropdown menu and quantity input
- Real-time updates to inventory display
- Modular design separating backend logic and GUI code
- Minimal setup, runs with Python only

---

## Technologies Used

- **Python 3**
- **Tkinter** (built-in GUI toolkit in Python)
